Description
This project is a dashboard-style practical programs website. The home page links to separate HTML, CSS and JavaScript program lists. Every experiment is stored as a separate HTML file and includes a short Program Description followed by a Working Demonstration.

How to Run
Extract the ZIP folder.
Open index.html in Chrome, Edge or another modern browser.
Select HTML, CSS or JavaScript Programs.
Open any experiment from the list.
Use the Home / Back to Programs navigation on each page.
Notes
Most demonstrations work directly by opening the HTML files.
API-based demonstrations require an internet connection.
Browser geolocation requires browser permission.
Audio/video experiments contain a demonstration area and can be connected to a local media source if required.
The project uses meaningful filenames and responsive styling.
