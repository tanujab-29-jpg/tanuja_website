## Project Description

This project is a **dashboard-style Practical Programs Website** developed for the Web Technology and Internet Programming practical assignment.

The home page provides navigation to separate **HTML, CSS, and JavaScript** program lists. Each experiment is stored as an individual HTML file and contains a **Program Description** followed by a **Working Demonstration**.

The website is designed with responsive styling and meaningful filenames to make the practical programs easy to access, understand, and execute.

## How to Run

1. Extract the ZIP folder.
2. Open the project folder.
3. Open **`index.html`** in Google Chrome, Microsoft Edge, or another modern web browser.
4. Select **HTML Programs**, **CSS Programs**, or **JavaScript Programs**.
5. Select any experiment from the corresponding program list.
6. Read the program description and view the working demonstration.
7. Use the **Home** or **Back to Programs** navigation to return to the program lists.

## Important Notes

* Most demonstrations can be executed directly by opening the HTML files in a browser.
* API-based demonstrations require an active internet connection.
* Geolocation experiments require browser permission.
* Audio and video experiments include demonstration areas and can be connected to local media files when required.
* Some browser features may behave differently depending on the browser.
* The project uses responsive styling so that the pages can be viewed on different screen sizes.
